# توقيع إصدار Android الرسمي

يجب إنشاء مفتاح توقيع واحد والاحتفاظ به بأمان طوال عمر التطبيق. لا تنشئ مفتاحًا جديدًا لكل إصدار، ولا ترفع ملف keystore أو كلمات مروره إلى Git.

## أسرار GitHub المطلوبة

من المستودع افتح Settings ثم Secrets and variables ثم Actions ثم New repository secret، وأضف:

- ASMAK_KEYSTORE_BASE64: محتوى ملف keystore بعد تحويله إلى Base64.
- ASMAK_STORE_PASSWORD: كلمة مرور مخزن المفاتيح.
- ASMAK_KEY_ALIAS: اسم المفتاح.
- ASMAK_KEY_PASSWORD: كلمة مرور المفتاح.

بعد إضافة الأسرار، سيبني سير العمل APK موقّعًا. إذا لم تُضف الأسرار، سيبني APK تجريبيًا Debug فقط، وليس إصدارًا صالحًا للتحديث الرسمي.

## تنبيه أمني

احتفظ بنسخة احتياطية مشفرة من ملف keystore وكلمات المرور في مكانين آمنين. فقدان المفتاح يعني عدم القدرة على إصدار تحديثات موقعة بنفس شهادة التطبيق. لا تشارك هذه الأسرار في المحادثة أو في ملفات المستودع.

## هوية التطبيق

سيتم إنشاء مشروع Android باستخدام معرّف الحزمة الثابت com.asmak.albaraka. لا تغيّره بعد نشر أول نسخة رسمية.
