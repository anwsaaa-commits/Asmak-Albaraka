# أسماك البركة

تطبيق Flutter لإدارة حجوزات بيع الأسماك بالكيلو، باللغة العربية وباتجاه RTL، مع حفظ محلي للبيانات والعمل دون اتصال بالإنترنت في الوظائف الأساسية.

## الوظائف الموجودة في المصدر

- إضافة أنواع الأسماك وتعديل سعر الكيلو وأرشفة الصنف.
- إنشاء حجز للعميل مع عدة أصناف وأوزان بالكيلو.
- تثبيت سعر الكيلو داخل تفاصيل الحجز حتى لا تتغير الحجوزات القديمة عند تعديل السعر.
- تحديد موعد الاستلام واسم العميل ورقم الهاتف والملاحظات.
- حالات الحجز: جديد، مؤكد، قيد التجهيز، تم التسليم، ملغي.
- تسجيل الدفعات الجزئية ومنع تجاوز إجمالي الحجز.
- عرض العملاء وإجمالي تعاملاتهم والمبالغ المتبقية.
- شاشة تحصيل الديون.
- ملخص مبيعات يومي وشهري.
- نسخ قاعدة البيانات واستعادتها بعد التحقق من جداولها.

## التقنية

- Flutter / Dart.
- SQLite عبر sqflite.
- معرّف Android الثابت: `com.asmak.albaraka`.
- اسم الحزمة في Dart: `albaraka`.

## بناء APK تجريبي

GitHub Actions يشغّل فحص Dart والاختبارات ثم يبني APK تجريبيًا عند عدم إعداد مفتاح الإصدار. النسخة Debug للاختبار فقط وليست تحديثًا رسميًا.

## إعداد الإصدار الرسمي الموقّع

راجع [دليل توقيع Android](docs/ANDROID_RELEASE_SIGNING.md). يلزم إعداد أسرار المستودع الأربعة التالية من حزمة التوقيع الخاصة:

- `ASMAK_KEYSTORE_BASE64`
- `ASMAK_STORE_PASSWORD`
- `ASMAK_KEY_ALIAS`
- `ASMAK_KEY_PASSWORD`

لا ترفع ملف `.jks` أو `android/key.properties` أو كلمات المرور إلى Git. يجب الاحتفاظ بنسخة آمنة من مفتاح التوقيع؛ لا تنشئ مفتاحًا جديدًا للتحديثات المستقبلية.

## ملاحظة الحالة

المصدر في مرحلة التطوير الأولي. يجب انتظار نجاح GitHub Actions، وتجربة APK على هاتف Android، والتحقق من جميع العمليات والنسخ الاحتياطي قبل اعتباره إصدارًا جاهزًا للاستخدام التجاري.

## اختبار النسخة التجريبية

يتم تشغيل فحص الكود والاختبارات وبناء APK من نوع Debug عبر GitHub Actions. لا يتطلب هذا البناء مفاتيح التوقيع الرسمية.
