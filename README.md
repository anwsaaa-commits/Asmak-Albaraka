# أسماك البركة

تطبيق Flutter لإدارة حجوزات بيع الأسماك بالكيلو.

## المبادئ الأساسية
- واجهة عربية كاملة باتجاه RTL.
- العمل دون اتصال بالإنترنت للعمليات الأساسية.
- تخزين محلي للبيانات باستخدام SQLite.
- إدارة الأصناف والأسعار والعملاء والحجوزات والمدفوعات.
- حفظ سعر الكيلو وقت إنشاء الحجز لضمان صحة السجلات التاريخية.
- تقارير يومية وشهرية ونسخ احتياطي واستعادة.

## حالة المشروع
بدأ تأسيس المشروع. ستتم إضافة الشاشات وقاعدة البيانات والاختبارات تدريجيًا، ولن تُعتبر نسخة APK جاهزة قبل نجاح البناء والاختبارات والتحقق من وظائف التطبيق.

## التشغيل
يتطلب Flutter SDK. بعد اكتمال ملفات المنصة:

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```
